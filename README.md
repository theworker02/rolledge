# rolledge

Roll validation gates for edge inputs before they hit prod.

**Site:** https://theworker02.github.io/rolledge/

## Install / run

```bash
git clone https://github.com/theworker02/rolledge.git
cd rolledge
node src/cli.js
node --test
```
